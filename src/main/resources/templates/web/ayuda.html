Instalar PulseDesk

PulseDesk (el helper) es el pequeño programa que abre la sesión remota en tu equipo cuando pulsas Conectar o Shadow. Se instala una sola vez por usuario, sin permisos de administrador.

PulseDesk (helper) para Windows

Ejecutable para Windows (64 bits). No requiere instalar nada más.

Cómo instalarlo

  1. 1

    Descarga el ejecutable y ábrelo. La primera vez Windows puede avisar (Más información → Ejecutar de todas formas).

  2. 2

    Cuando lo pida, pega la dirección del portal: https://serverhcpi.tailb40f15.ts.net

  3. 3

    Listo. Vuelve al portal y pulsa Conectar: se abrirá la sesión remota automáticamente.
